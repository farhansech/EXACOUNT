# Build e-book "10 Upgrade yang Mengubah Hidup"

    python3 ebook-build/make.py

Foto manusia realistis: simpan sebagai `ebook-build/photos/p01.jpg` ... `p10.jpg` (satu per Upgrade).
Opsional `p01.txt` berisi kredit fotografer/lisensi (ditampilkan di bawah foto dan di halaman Catatan Akhir).
Tanpa file foto, halaman menampilkan bingkai penanda. Teks tinjauan ilmiah & referensi ada di `content.py`.
